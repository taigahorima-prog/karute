# 牛カルテ 病傷入力アプリ 更新版

## 変更点
- 病名マスタ（病名コード・病名・常用・原因）を参照して第一・第二病名を選択
- 原因1/原因2はそれぞれの病名から自動入力、手修正可能
- 再診時は同じカルテ番号の前回TPRを読み込み、増減ボタンで編集
- TPR区分は「未測定」「前回値からの推定」「実測」から選択。診療シートに「TPR区分」列を追加すると区分も保存できます（列がなければ値のみ保存され、区分は保存されません）。
- 処置明細の処置単位「回」は空欄に変更

## 導入
1. GitHub リポジトリ直下の index.html をこのファイルで置換してコミット
2. スプレッドシートに紐付いた Apps Script の Code.gs を置換
3. Apps Script を新バージョンで再デプロイ
4. GitHub Pages のキャッシュを更新して再読込
5. テストデータで病名選択・原因・再診TPR・3シート保存を検証

## 注意
- 実測していないTPRは推定値と区別して扱ってください。
- GASを「全員」に公開する構成は診療情報の実運用には適しません。認証とアクセス制限が必要です。
- 本番接続でのテストは未実施です。
